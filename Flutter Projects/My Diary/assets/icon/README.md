Place your launcher icon here as a 1024x1024 PNG named `app_icon.png`.

- Recommended: 1024×1024 PNG, square, no transparent background (for launcher icons).
- File path used in `pubspec.yaml`: `assets/icon/app_icon.png`.

After adding `app_icon.png`, run:

```
flutter pub get
flutter pub run flutter_launcher_icons:main
```
